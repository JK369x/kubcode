# life-story — เรื่องชีวิต (fiction)

**เรื่องชีวิต · English: Life Story** (key `life-story`)

Formula: **ปัญหาใกล้ตัว → ความรู้สึก → ทางออกเล็กๆ ทำได้วันนี้**
Seen with visual style: `soft-2d` (any visual style is allowed). Legacy series names: `jk-soft-story`,
`jk-soft-story-motion-v2`.

## Beats (≈ 29–40 s, 8 lines)
| # | beat | what it does |
|---|---|---|
| 1 | hook (0–2 s) | open inside the problem: "วันแรกที่ทำงาน คำถามเต็มหัว แต่ไม่กล้าถามสักข้อ" |
| 2 | concrete detail | 2–3 tiny real-life specifics (ห้องน้ำอยู่ไหน พักเที่ยงกี่โมง) |
| 3 | feeling | the fear/sadness in one honest line |
| 4 | reframe | "แต่จริงๆ แล้ว…" — it is common, nobody's fault |
| 5–7 | small fixes | 1–3 practical steps that can be done today, each one picture |
| 8 | payoff | one warm line; end on the character doing the small thing |

## Length / words
Real clips 28.9–39.3 s, ≈ 300–480 Thai characters.

## Tone
Warm, empathetic, gentle; no lecturing, no statistics needed. Everyday Thai work/family/friend situations.

## Fact / fiction
The characters and scene are fiction (a generic "us"). Advice must be ordinary, safe and hedged
("กฎทั่วไป ไม่ใช่กฎหมาย"). If a number is used (e.g. sleep 7–9 h) it needs a source note in SCRIPT.md.
No medical, legal or financial claims beyond common guidance.

## Captions (content)
Amber = key tip, coral = the fear/mistake, cyan = the reframe/alternative.

## Voice
Local JK `approved-calm-male-v1`. ElevenLabs only with the owner's own voice `jk` and spend approval.
