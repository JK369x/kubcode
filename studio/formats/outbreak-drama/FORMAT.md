# outbreak-drama — ห้างติดเชื้อ (fiction, serial)

**ห้างติดเชื้อ · English: Mall Outbreak** (key `outbreak-drama`)

Formula: **ซีรีส์ต่อเนื่อง ระทึก**
Seen with visual style: `low-poly` (any visual style is allowed). Legacy series name: `mall-infection`.

## Beats per episode (≈ 85–100 s, 10–12 sections)
Rules-horror shape from EP1 "กฎ 3 ข้อ":
1. hook — the world is already wrong ("ห้างปิดแล้ว แต่คนที่เดินอยู่ข้างล่าง ไม่ใช่ลูกค้าอีกต่อไป") + promise (rules)
2. setup — where "you" are, one resource number (มือถือ 7%), the note with rules
3. rule → proof, ×3 — each rule is demonstrated by an event right after it is read
4. near-miss — using a rule to escape
5. twist — the last rule turns against you (the speaker uses mum's voice; the real mum texts)
6. choice — two exits with clear risk; **viewer vote** decides the next episode

## Length
Real clips 86.4 s and 97.2 s; length comes from measured audio, not word counts.

## Fiction rules
- Fictional rules-horror; not real emergency guidance — say so in the script, do not present rules as advice.
- Continuity: location map, resources and wounds stay consistent across episodes.

## Tone
Tense, second person, short sentences, deliberate handoff pauses. No gore close-ups.

## Captions (content)
Rule numbers in amber, prohibitions in coral, clues (wet footprints, the text message) in cyan.

## Voice
Local JK `approved-calm-male-v1`, normal speed/pitch. ElevenLabs only with the owner's own voice `jk` and spend
approval.
