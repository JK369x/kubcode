# what-if — ถ้าเกิดว่า… (fiction + fact)

**ถ้าเกิดว่า… · English: What If** (key `what-if`)

Formula: **สมมติ 1 ข้อ → ผลลัพธ์ทีละขั้น → ข้อเท็จจริงจริง 1 ข้อ → คำถามปิด**
Seen with visual style: `stick-svg` (any visual style is allowed). Legacy series names: `freshstack-what-if`,
`what-if-studio`.

## Beats (≈ 32–44 s Thai shorts, 7–9 lines)
| # | beat | what it does |
|---|---|---|
| 1 | hook (0–2 s) | the premise as a question while the picture already shows it: "ถ้าพรุ่งนี้ อินเทอร์เน็ตหายไปทั้งโลก หนึ่งสัปดาห์ล่ะ?" |
| 2–4 | consequences step by step | DAY 1 / DAY 3 / … or small → bigger → uncanny; each line is one picture |
| 5 | the real fact | one true, checked fact (ideally with a number) that turns or grounds the scenario ("GPS ยังบอกตำแหน่งได้ เพราะฟังดาวเทียม") |
| 6 | takeaway (optional) | one practical thing that is actually true |
| 7 | closing question | open question to the viewer, never a tidy resolution |

The upstream "seven-beat" English formula (cold open with 3 demos → premise → fun → cost "That's real." →
cliffhanger, 45–65 words, 15–25 s) is the short 16:9 variant used in `what-if-studio` ep01 (Mute Touch, 23.9 s).

## Length / words
Real Thai clips 32.8–44.1 s, ≈ 370–520 Thai characters.

## Fiction + fact rules
- The premise and its consequences are a scenario; frame them as "ถ้า / สมมติ", not as forecasts.
- The fact beat is real: write the claim, the working (arithmetic) and the source in "Fact check" in SCRIPT.md
  before voicing. Never invent a number or round it into a different claim.
- No real people, brands or famous characters.

## Tone
Curious, brisk, second person, present tense. Slightly uneasy before the turn; warm closing question.

## Captions (content)
Amber for the premise keyword and numbers; coral for the cost; cyan for "what still works / the real fact".

## Voice
Local JK `approved-calm-male-v1` (all 2026-11-01 Thai episodes). ElevenLabs Thai only with the owner's own
voice `jk` and explicit spend approval — Mute Touch used a premade ElevenLabs voice; that is no longer allowed.
