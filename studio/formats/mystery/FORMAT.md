# mystery — ปริศนา (fact, with labelled imagination)

**ปริศนา · English: Mystery** (key `mystery`)

Formula: **คำถามชวนสงสัย → เบาะแส → คำตอบ**
Seen with visual style: `footage-reframe` (any visual style is allowed). Legacy series name: `us-antarctica`.

## Beats (one clip so far: 40.4 s, 7 sections)
1. hook — concrete numbers + question ("เรือสิบสามลำ คนราวสี่พันเจ็ดร้อย… กองเรือนี้ไปหาอะไร")
2–3. documented facts — name, year, stated mission
4. the rumour — attributed and marked **ยังไม่ยืนยัน**
5–6. optional imagined scene — every frame labelled **ฉากจินตนาการ**
7. close — return the question to the viewer

## Fact / fiction layering
Facts first (sourced), then attributed lore (unconfirmed), then explicitly imagined content. Never blend the
three; each section is labelled on screen. A "คำตอบ" must be the documented answer, not the rumour.

## Length
≈ 40 s; balanced breathing room between sections.

## Captions (content)
Highlight-text only was used (no full-sentence captions); labels "เรื่องเล่า / ยังไม่ยืนยัน / ฉากจินตนาการ"
are mandatory content, not decoration.
