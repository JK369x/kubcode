# JK Soft Story

Read ../../../styles/jk-soft-story/STYLE.md relative to this skill and inspect that folder's assets/selected-v2.png. This is the canonical visual baseline selected on 2026-10-28. Assets and component SVGs are original editable artwork. The full scene is not a mandatory template for every story or country.

Keep rounded silhouettes, local soft material shading and selective narrow rim lighting. Do not simplify back to polygon hands, uniform thick yellow outlines or pale full-frame haze. Preserve named groups when rigging with HyperFrames. Prefix ids when merging SVGs.

Style selection covers still visual direction only; motion, sound and full episodes require their own inspection. Follow the repository DIRECTOR.md and TECHNIQUE.md. Voice is independent; use the bundled thai-narrator skill when the Thai narrator is requested (older notes call it "JK voice").
