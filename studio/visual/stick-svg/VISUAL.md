# stick-svg — ตัวละครเส้น SVG (Stick SVG)

**ตัวละครเส้น SVG · English: Stick SVG** (key `stick-svg`)

Look only. First paired with `formats/what-if`.
Kit: `styles/freshstack-what-if/` (`kit/`, `source/studio/`, look notes in `kit/references/look.md`). Status: **draft**.

## Look
- Stick figures on one SVG rig (hooded "Pip" and friends) inside rooms drawn in perspective.
- Dusk palette (purple → orange sky, low sun); muted mid-dark walls so practicals read; every light comes
  from something visible (window, pendant, desk lamp, string lights).
- Warm rim light on the lit edge of each character; haze, dust in beams, bokeh, grain on twos, soft vignette.
- A blueprint/schematic set for the "this is real" fact beat.

## Camera
Fast pace: median shot 0.7–3 s; cuts by changing shot size (wide → macro insert → medium → close-up → reaction);
no two neighbouring shots share size and angle; motivated moves only.

## Renderer
React SVG / Remotion 4.0.530 (+ host FFmpeg master). Remotion has its own licence terms. Our Thai
episodes were re-framed to 9:16.
