# JK Soft Story — Motion Beats v2

Draft, opt-in motion experiment. This is a separate pilot built from the existing JK Soft Story 8-second motion scene. It does not replace the selected still style or the existing motion study. The scene and character geometry remain editable; the output is silent and its bilingual text demonstrates timing only, not spoken-word alignment.

The comparison of locally supplied Genhaha horror and map skills suggests shot-by-shot intent, a question first, successive visual focus and restrained changes of camera. This experiment adapts those general ideas without copying or redistributing their kits. It uses three text beats and three modest reframings, timed to the existing hand, latch and approaching figure. Keep captions scene-aware; use the selected shared Thai-keyword/English caption direction for narrated work. Actual spoken duration must drive future cues.

Source provenance: `styles/jk-soft-story/examples/motion/index.html` and local GSAP asset. Genhaha source references: the user-provided Genhaha Horror and Map `SKILL.md` files. Their completed output pipelines include narration and effects, but this experiment does not implement them. Respect their LICENSE.md when using their kits.

Render from the repo root:

```
node_modules/.bin/hyperframes render styles/jk-soft-story-motion-v2/examples/pilot --fps 30 --quality draft --workers 1 -o "$PWD/outputs/comparison-20261029/jk-motion-v2-readable-8s.mp4"
```

Audio-first Thai narrator, shot-level narration, sound design and review are future work, not covered by this silent pilot.
