## อ่านก่อนรัน

SKILL.md เป็นคำแนะนำให้ agent ทำงาน บางชุดแนบ scripts หรือ kit ที่รันได้ แต่การมีเอกสารไม่ได้รับประกันว่ามีโปรแกรมครบ ก่อนติดตั้งให้ตรวจ README, runtime, dependency และ entrypoint จากชุดจริง อย่าคัดคำสั่งโดยไม่รู้ว่าจะเขียนไฟล์ที่ไหน ส่งข้อมูลออกไปหรือเรียก provider ใด

## ทำรายการสิ่งที่เครื่องต้องมี

แยก Node, Python, FFmpeg, browser และฟอนต์ออกจากบริการเสียงหรือโมเดลที่ต้องดาวน์โหลด ตัวอย่างเสียงของ Thai Calm Narrator ใช้ MLX บน Apple Silicon macOS และ Python 3.11+ จึงไม่ควรอ้างว่ารันบน Windows ได้ด้วยคำสั่งเดิม การเริ่มต้นอาจใช้ network และพื้นที่ดิสก์ แม้หลังติดตั้งแล้วจะทำงานในเครื่องได้

## สิทธิ์มีหลายชั้น

ตรวจแยกสิทธิ์ของโค้ด kit, ภาพตัวอย่าง, ฟอนต์, เสียง, model weights และ renderer การสมัครสมาชิกฟรีไม่ได้ทำให้ provider ภายนอกฟรี หรืออนุญาตให้ re-upload ชุดเชิงพาณิชย์ เก็บ provenance และรุ่นที่ใช้ไว้ เพื่อให้รู้ว่าไฟล์ใดมาจากที่ใด ไม่รวม secret, credential หรือการอนุมัติใช้เงินไว้ใน bundle

## ทดสอบเล็ก แล้วบันทึกสิ่งที่เห็นจริง

เริ่มจากตัวอย่างสั้นในโฟลเดอร์แยก ตรวจไฟล์ output และรายงานผลจริง ระบุว่าทดสอบแค่ typecheck, render ภาพเงียบ หรือ MP4 พร้อมเสียง อย่าอ้างว่า clean-clone render ผ่านจากการดูคลิปเดิม บนเว็บไซต์นี้การดาวน์โหลดยังปิดอยู่ เพราะยังไม่เชื่อมระบบสมาชิกและยังไม่เคลียร์สิทธิ์แจกจ่าย
