## make-short คืออะไร

[make-short](/tools/make-short) เป็น skill ฟรี (MIT) ของ NoCodeHack สำหรับ [Claude Code](/tools/claude-code) พิมพ์ไอเดียหนึ่งบรรทัด แล้ว Claude จะพาทำคลิปสั้นแนวตั้งที่มีตัวละครทรงเมล็ดถั่วในโลก 3D แบบภาพวาด มีเสียงพากย์ ซับ และเสียงประกอบ ทุกฉากเป็นสคริปต์ Python ที่ [Blender](/tools/blender) เรนเดอร์ในเครื่องเรา ไม่ใช้โมเดลสร้างภาพหรือวิดีโอ

ที่น่าสนใจที่สุดคือ **critic แยกตัว** หลังเรนเดอร์ skill จะเปิด agent ใหม่ที่ไม่ได้สร้างคลิปมาให้คะแนนตาม rubric โดยบอกวินาทีของทุกจุดที่หักคะแนน ผู้เขียนพบว่า Claude ให้คะแนนงานตัวเอง 6.5 จาก 10 แต่ critic ให้ภาพเดียวกันแค่ 4.2 หลังแก้ตาม critic หลายรอบ คะแนนขึ้นไปถึง 7.9

## ขั้นตอนที่ skill พาทำ

1. **วัดคลิปต้นแบบ** (ถ้ามี): แตกคลิปที่ชอบเป็นตัวเลข เช่น จำนวนช็อต ความสว่าง สี
2. **เขียนเรื่อง:** ใช้สูตร paradox คือเปิดด้วยสองเรื่องจริงที่ไม่น่าจะจริงพร้อมกัน แล้วเฉลยด้วยข้อเท็จจริง **คุณต้องอนุมัติเรื่องก่อน**
3. **เสียง:** อัดเสียงตัวเองฟรี แล้วให้ Whisper จับเวลาทุกคำ หรือใช้ [ElevenLabs](/tools/elevenlabs) (ราว 1 เครดิตต่อตัวอักษร skill บอกจำนวนตัวอักษรก่อนสร้าง)
4. **สร้างช็อต:** เขียน `shots.json`, `acting.json` และฉาก Blender คลิปยาวใช้ทีม agent ช่วยกัน
5. **ด่านตรวจ:** เรนเดอร์ภาพนิ่งช็อตละภาพ ตรวจทั้งตัวเลขและด้วยตา **คุณสั่ง render เอง**
6. **critic:** agent ใหม่ให้คะแนนและเขียนจุดที่ต้องแก้ 3 ข้อตามช่วงเฟรม
7. **แก้:** แก้เฉพาะช่วงที่ critic ชี้ แล้วเรนเดอร์ใหม่
8. **โพสต์:** ไม่บังคับ ถ้าต่อ Blotato จะอัปโหลดแบบ private หลังคุณพิมพ์ `go` เท่านั้น

## เราลองบน Mac: ได้ผลจริง

ต้นทางเขียนไว้สำหรับ Windows กับ Git Bash เราลองบน MacBook (Apple M5, Blender 5.3, Node 24, FFmpeg 9) และพบว่าต้องแก้ 4 จุดในโฟลเดอร์โปรเจกต์:

- คำสั่ง `pwd -W` มีแค่ใน Git Bash บน Mac ต้องใช้ `pwd`
- สคริปต์เรียก `python` แต่ Mac มี `python3`
- หา Blender ใน `C:\Program Files` ต้องชี้ไปที่ `/Applications/Blender.app`
- ไฟล์ `.sh` ที่คัดลอกมายังไม่ได้ตั้งสิทธิ์ให้รันได้

เราเขียน `kubcode/mac-patch.sh` แก้ทั้ง 4 จุดให้ (แก้แค่สำเนาโปรเจกต์ ไม่แตะไฟล์ต้นทาง) มีอยู่ในชุดที่ดาวน์โหลดจากหน้า [skill](/skills/make-short) ผลที่ได้:

- **ตรวจไฟล์เสียง (`node --check`):** ผ่านทั้ง 4 ไฟล์
- **ตรวจแผนช็อตตัวอย่าง 60 วินาที:** 39 ช็อต ไม่มี error
- **ด่านตรวจภาพนิ่ง 2 ช็อต:** PASS 2/2 ใน 38 วินาที
- **เรนเดอร์ 15 วินาทีแรก (450 เฟรม, 1080×1920):** 437 วินาที หรือราว 7.3 นาที

เราลองแค่ส่วนภาพ ส่วนเสียง การมิกซ์ และรอบ critic ยังไม่ได้ลองบน Mac

```bash title="mac-setup.sh"
brew install --cask blender && brew install ffmpeg node
python3 -m pip install --user pillow numpy
cp -R ~/.claude/skills/make-short/v3 ~/shorts/my-short
bash ~/.claude/skills/make-short/kubcode/mac-patch.sh ~/shorts/my-short
```

## ค่าใช้จ่ายจริง

- **skill และ Blender:** ฟรี
- **Claude:** ต้นทางรายงานว่าคลิป 15 วินาทีใช้เวลา 26 นาที ใช้ราว 3% ของโควตา 5 ชั่วโมงในแผน Max 5x หรือราว $5 ถ้าคิดราคา API ถ้าใช้แผน Pro จะกินโควตาราว 5 เท่า
- **เสียง:** อัดเองฟรี ถ้าใช้ ElevenLabs คลิป 15 วินาทีใช้ราว 202 เครดิต
- **รอบแก้:** เป็นส่วนที่กินโควตามากที่สุด จะแก้กี่รอบเลือกเองได้

## ข้อควรรู้ก่อนใช้

- ใช้ได้กับ Claude Code เท่านั้น อัปโหลดเป็น Skills บน claude.ai ไม่ได้ เพราะต้องรัน Blender ในเครื่อง
- ต้องมีการ์ดจอที่ Blender ใช้ได้ ถ้าใช้แค่ CPU จะช้ามาก
- ฉากและตัวละครที่มีมาคือค่ายทหาร ถ้าเรื่องต้องใช้ฉากหรือตัวละครใหม่ ต้องแก้ `lib/sets.py` หรือ `lib/chars.py` และเผื่อเวลา
- เสียงพากย์และ Whisper ตั้งค่าเป็นภาษาอังกฤษ ถ้าจะทำภาษาไทยต้องเปลี่ยนภาษาของ Whisper และหาเสียงไทยเอง
