## ต้นทางของบทความนี้

FreshStack เผยแพร่คู่มือทำคลิปแอนิเมชันสั้นแนว "ถ้าเกิดว่า…" (What If) โดยไม่ต้องจ่ายค่าโมเดล AI แนวคิดหลักคือใช้ผู้ช่วยเขียนโค้ดที่เป็นโอเพนซอร์ส คู่กับโมเดลที่เปิดให้ใช้ฟรีชั่วคราว แล้วให้ skill สำเร็จรูปพาไปตั้งแต่เขียนบทจนได้ไฟล์ MP4 บทความนี้สรุปเส้นทางนั้นด้วยคำของเราเอง เพิ่มสิ่งที่เราเจอจากการลองจริง และเพิ่มทางเลือกสำหรับเสียงพากย์ไทยกับซับไทย อ่านรายละเอียดเต็มและคำสั่งที่ถูกต้องได้จาก[บทความต้นทาง](https://www.freshstack.ai/resources/free-ai-animation)และ [README ของ skill](https://github.com/kelano86/what-if-animation)

## แยกชั้นให้ออกก่อน

คลิปหนึ่งตอนเกิดจากหลายชั้นที่เปลี่ยนแยกกันได้ ถ้าแยกไม่ออกจะสับสนว่าอะไรฟรี อะไรต้องขออนุญาต (อ่านแนวคิดนี้เพิ่มใน[สไตล์ ผู้เขียน และ renderer ไม่ใช่สิ่งเดียวกัน](/articles/style-author-renderer))

- **ผู้เขียนโค้ด:** [OpenCode](/tools/opencode) ทำหน้าที่แบบเดียวกับ Claude Code คืออ่านไฟล์ รันคำสั่ง และเขียนโค้ดในโฟลเดอร์งาน
- **โมเดล:** [GLM-5.3-Flash Free](/tools/glm-5-3-flash) ที่เลือกได้ในเมนูโมเดลของ OpenCode
- **วิธีทำงาน:** [What If animation skill](/tools/what-if-animation) กำหนดขั้นตอนทั้งหมดและแนบโปรเจกต์ Remotion มาให้
- **ตัวเรนเดอร์:** [Remotion](/tools/remotion) แปลงฉาก SVG ที่ AI เขียนให้เป็นวิดีโอ
- **เสียง:** [ElevenLabs](/tools/elevenlabs) สร้างเสียงบรรยายและเสียงประกอบ
- **ประกอบไฟล์:** [FFmpeg](/tools/ffmpeg) จัดการเสียง ภาพ และปรับความดังรวม

## เครื่องต้องมีอะไร

- Node.js 18 ขึ้นไป สำหรับ Remotion
- Python 3.9 ขึ้นไป พร้อมแพ็กเกจ numpy และ Pillow สำหรับสคริปต์ช่วย
- FFmpeg ที่มี ffprobe มาด้วย
- บัญชี ElevenLabs แบบฟรี และ API key เก็บไว้ในไฟล์ `.env` ของโฟลเดอร์งาน
- ไม่ต้องสมัครบัญชีเพื่อใช้ OpenCode หรือโมเดลฟรีของมัน

ต้นทางไม่ได้ระบุสเปกเครื่องขั้นต่ำ การเรนเดอร์ครั้งแรกจะติดตั้ง dependency ของ Remotion จึงใช้เวลาเพิ่มอีกหลายนาที

ก่อนเริ่ม เราใช้สคริปต์สั้น ๆ นี้ตรวจว่าเครื่องพร้อมหรือยัง ถ้าบรรทัดไหนขึ้น error ให้ติดตั้งตัวนั้นก่อน

```bash title="check-setup.sh"
# Each line prints a version, or fails if the tool is missing.
node --version                               # needs 18 or newer
python3 -c "import numpy, PIL; print('python ok')"
ffmpeg -version | head -n 1
ffprobe -version | head -n 1
test -f .env && grep -q ELEVENLABS_API_KEY .env && echo "api key ok"
```

## ลำดับการตั้งค่า

1. ติดตั้ง Node.js, Python และ FFmpeg ด้วยตัวจัดการแพ็กเกจของระบบ (Homebrew บน Mac, winget บน Windows)
2. ติดตั้ง OpenCode จากแพ็กเกจ npm ชื่อ `opencode-ai`
3. สร้างโฟลเดอร์สำหรับงานแอนิเมชันโดยเฉพาะ และเปิด OpenCode จากในโฟลเดอร์นั้นทุกครั้ง ถ้าเปิดที่อื่น OpenCode จะหา skill ไม่เจอ
4. ในเมนูเลือกโมเดล เลือก GLM-5.3-Flash Free และตั้ง reasoning เป็นระดับสูง
5. วาง skill ไว้ในโฟลเดอร์ skills ของโปรเจกต์ แล้วคัดลอกไฟล์คำสั่ง `/what-if` ของ skill ไปไว้ในโฟลเดอร์คำสั่งของ OpenCode ตามที่ README บอก เพราะ OpenCode ไม่แสดง skill ในเมนู slash เอง
6. ใส่ ElevenLabs API key ในไฟล์ `.env`
7. พิมพ์ `/what-if` ตามด้วยคำถาม "ถ้าเกิดว่า…" หนึ่งบรรทัด

## agent ทำอะไรให้ในหนึ่งตอน

หลังสั่งงาน agent จะเดินตามขั้นตอนของ skill เอง: เขียนบทสั้นที่มีข้อเท็จจริงจริงหนึ่งข้อพร้อมแหล่งอ้างอิง สร้างเสียงบรรยายพร้อมเวลาของแต่ละคำ วางลำดับช็อตให้ตรงกับคำพูด ทำสตอรีบอร์ดภาพนิ่งแล้วตรวจกับรายการตรวจของ skill เขียนฉากเป็น SVG แล้วเรนเดอร์ด้วย Remotion เติมเสียงประกอบ และปรับความดังรวมด้วย FFmpeg ผลลัพธ์คือ MP4 ยาวราว 15–25 วินาที พร้อมภาพสตอรีบอร์ด ตัวละครหน้าตาคงที่ทุกตอนเพราะวาดด้วยโค้ด ไม่ได้สุ่มจากโมเดลสร้างภาพ

## คำว่า "ฟรี" มีเงื่อนไข

- **GLM-5.3-Flash Free** ฟรีเฉพาะผ่าน OpenCode Zen และเป็นข้อเสนอแบบมีระยะเวลา ถ้าเรียกรุ่นเดียวกันผ่าน API ของ Z.ai โดยตรงจะเสียเงิน ส่วนรุ่นที่ Z.ai เปิดฟรีบน API ของตัวเองคือรุ่นเก่ากว่า เช่น GLM-4.7-Flash
- **ElevenLabs แผนฟรี** ได้เครดิตเดือนละ 10,000 ซึ่งต้นทางใช้ราว 150–250 เครดิตต่อตอน แต่ห้ามใช้เชิงพาณิชย์ และถ้าเผยแพร่ต้องใส่ "elevenlabs.io" ไว้ในชื่อคลิปตามเงื่อนไขของ ElevenLabs ถ้าจะหารายได้จากช่องต้องอัปเกรดเป็นแผนที่มีสิทธิ์เชิงพาณิชย์
- **Remotion** ใช้ฟรีได้สำหรับบุคคล องค์กรไม่แสวงกำไร และบริษัทที่มีพนักงานไม่เกิน 3 คน เกินกว่านั้นต้องซื้อ Company License
- **ตัว skill** ใช้สัญญาอนุญาต MIT ส่วนฟอนต์ที่โหลดตอนเรนเดอร์ใช้ SIL Open Font License

## ข้อจำกัดที่ต้นทางบอกไว้ตรง ๆ

โมเดลฟรีรันตาม skill ได้จนจบโดยไม่ต้องช่วย แต่สร้าง skill ใหม่เองได้ไม่ดีเท่าโมเดลแบบเสียเงิน และพลาดการค้นหาช่องที่ทำหัวข้อเดียวกันไปแล้ว ต้นทางจึงแนะนำให้ใช้โมเดลที่แรงกว่าตอนสร้าง skill แล้วใช้โมเดลฟรีตอนผลิตแต่ละตอน ข้อควรทำที่เราเห็นด้วย:

- เริ่ม session ใหม่ทุกตอน เพราะหนึ่งตอนกิน context ของโมเดลไปมาก
- ค้นหาเองว่ามีคนทำหัวข้อเดียวกันแล้วหรือยัง
- เปิดแหล่งอ้างอิงของข้อเท็จจริงในบทด้วยตัวเองก่อนโพสต์
- ใช้ตัวละครและเรื่องที่คิดเอง ไม่เลียนแบบตัวละครหรือช่องที่มีชื่อเสียง

## เส้นทางเสียงไทยและซับไทยของเรา

### เสียงพากย์ไทย

ถ้าจะทำตอนภาษาไทย มีสองทางสำหรับเสียงพากย์

- **ElevenLabs รุ่นที่รองรับภาษาไทย** (Eleven v3 และ v4) ตอนทดลอง [What If Lab](/skills/freshstack-what-if) ของเราใช้เสียงบรรยายไทยจาก eleven_v3 ข้อจำกัดเรื่องเครดิตและการใช้เชิงพาณิชย์ยังเหมือนเดิม
- **[Thai Voice](/skills/thai-jk-voice)** เสียงบรรยายไทยสังเคราะห์ที่รันในเครื่อง Apple Silicon ด้วย MLX ไม่เสียค่าเครดิตต่อตอน แต่ต้องดาวน์โหลด weights และตรวจเงื่อนไขของต้นทางเองก่อนใช้

### ซับไทย

ซับไทยแยกเป็นอีกชั้น เราใช้ [Captions Overlay](/skills/captions-overlay) ซึ่งอ่านเวลาจากเสียงจริง แล้วใช้ adapter ให้ตรงกับ renderer ที่เลือก ต้องใช้ฟอนต์ไทยที่มีสิทธิ์ใช้งาน และอนุมัติรูปแบบซับแยกจากภาพและเสียง

## สรุป

> ก่อนกดเผยแพร่ ตรวจสามอย่าง: ชื่อคลิปมี "elevenlabs.io" ถ้าใช้เสียงจากแผนฟรี, ทีมของคุณยังอยู่ในเงื่อนไขฟรีของ Remotion, และข้อเท็จจริงในบทเปิดแหล่งอ้างอิงได้จริง
