## เริ่มที่ผลลัพธ์ ไม่ใช่ชื่อโมเดล

ก่อนเลือก skill ให้ถามว่าอยากเล่าอะไรและต้องส่งไฟล์แบบไหน สไตล์กำหนดภาษาภาพ เช่น แสง สัดส่วนตัวละคร และวัสดุ ส่วน Claude Code, Codex CLI หรือ OpenCode คือผู้เขียนโค้ด ไม่ใช่สไตล์ภาพ งานจากผู้เขียนคนเดียวกันจึงมีหน้าตาต่างกันได้ และสไตล์เดียวกันก็มีหลายผู้เขียนได้

## หกชั้นที่ต้องอ่านให้แยกกัน

หนึ่ง เรื่องและตอน: บทกับลำดับเหตุการณ์ สอง สไตล์: ภาพหน้าตาอย่างไร สาม ผู้เขียน: ใครจัดฉากหรือเขียนโค้ด สี่ renderer: ใช้อะไรสร้างและ export ภาพ ห้า เสียงและซับ: ใช้เสียงใด เวลาไหน และหก หลักฐาน: มี MP4, source หรือผลตรวจอะไรจริง การมีคลิปให้ดูยืนยันเพียงว่ามีตัวอย่าง ไม่ได้ยืนยันว่าติดตั้งจากเครื่องใหม่แล้วทำซ้ำได้ครบ

## ตัวอย่างเดียวกัน ไม่ใช่ pipeline เดียวกัน

Stickman Cinema ใช้ Canvas และ Chromium ในขณะที่ Survival Stories สร้าง SVG/HTML ด้วย Python และใช้ HyperFrames ส่วน What If Lab ใช้ React SVG กับ Remotion ข้อกำหนดและ scene contract ไม่เหมือนกัน อย่าคัดคำสั่งของชุดหนึ่งไปใช้อีกชุดเพียงเพราะภาพเป็น stick figure เหมือนกัน

## แยกการอนุมัติให้ละเอียด

การเลือกภาพนิ่งไม่ใช่การอนุมัติ animation การอนุมัติรูปแบบซับไม่ครอบคลุมเสียง และการมีสิทธิ์ใช้ชุดเครื่องมือส่วนตัวไม่ใช่สิทธิ์แจกต่อ อ่านขอบเขตของแต่ละตัวอย่างก่อนนำไปผลิตงานใหม่ เก็บกฎภาพที่ STYLE.md แหล่งเดียว และใช้เสียงหรือซับผ่าน shared workflow ที่อ้างถึงแทนการสร้างสำเนา
