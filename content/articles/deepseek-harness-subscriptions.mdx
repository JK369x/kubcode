## ทำไมถึงลอง

ตอนนี้เราจ่าย subscription ทั้ง Claude และ ChatGPT อยู่แล้ว แต่ต้องสลับไปมาระหว่างหลายแอป เลยอยากรู้ว่า [DeepSeek Harness](https://deepseek.com/harness/) จะเป็นโต๊ะทำงานกลางที่รวมทั้งสองบัญชีไว้ในหน้าจอเดียวได้ไหม และไม่ต้องใช้โมเดล DeepSeek เป็นตัวหลักตลอดเวลา

สรุปสั้น ๆ ก่อนอ่านต่อ: **ติดตั้ง Harness กับปลั๊กอิน subscription สำเร็จ เชื่อมบัญชี Claude และ ChatGPT/Codex ได้ และเลือก Claude เป็นโมเดลหลักในแชตใหม่ได้** แต่เรายังไม่ได้ทดสอบให้โมเดลทั้งสองตอบงานจริงครบเส้นทางผ่านปลั๊กอินนี้ ตั้งค่าสำเร็จกับใช้งานได้ครบทุกอย่างเป็นคนละเรื่องกัน

## DeepSeek Harness คืออะไร

Harness เป็นโปรแกรมที่รันบน Mac ของเรา แล้วเปิดหน้าควบคุมเป็นเว็บในเครื่อง (`127.0.0.1`) ในหน้านั้นเลือกโฟลเดอร์งาน (workspace) เปิดแชตหลาย session และให้ agent อ่านหรือแก้ไฟล์ รันคำสั่ง แบ่งงานย่อย และวางแผนงานได้ตามสิทธิ์ที่เราตั้งไว้

ข้อที่ควรเข้าใจให้ตรง: **หน้าเว็บอยู่ในเครื่อง แต่ตัวโมเดลไม่ได้รันในเครื่อง** ทุกครั้งที่คุยกับ Claude หรือ Codex คำขอยังถูกส่งไปที่บริการของแต่ละเจ้าเหมือนเดิม ตอนนี้ Harness ยังเป็นรุ่น developer preview ส่วนต่าง ๆ อาจเปลี่ยนได้

## ติดตั้งบน Mac

เครื่องที่เราใช้เป็น Mac ชิป Apple Silicon มี Node.js 24.22.2 และใช้ pnpm 11.28.5 ตามรุ่นที่ repo กำหนด (เรียกผ่าน `corepack`) ตัว Harness ที่ได้คือรุ่น 0.2.2-rc.1

```bash title="install-harness.sh"
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
corepack pnpm install      # Done in 22.5s
corepack pnpm run build    # run-gates: 10 passed, 0 failed, 0 skipped in 90.37s
corepack pnpm dsh web      # opens the local web UI at 127.0.0.1:3080
```

ผลที่ได้:

- ติดตั้ง dependency ใช้เวลา 22.5 วินาที และ build ผ่านทั้ง 10 ขั้นใน 90.37 วินาที
- หน้าเว็บเปิดที่ `http://127.0.0.1:3080/` ถ้ายังไม่ได้ยืนยันตัวตน หน้าเว็บจะตอบ 401 แปลว่าคนอื่นเปิดโดยไม่มีสิทธิ์ไม่ได้
- เซิร์ฟเวอร์ผูกกับ loopback ของเครื่องเท่านั้น ไม่ได้เปิดเป็นเว็บสาธารณะ
- ลิงก์ที่เปิดตอนเริ่มโปรแกรมมีโทเคนเข้าระบบอยู่ อย่าแชร์ลิงก์นี้ให้คนอื่นหรือแปะลงในคลิป

คำสั่งด้านบนเป็นรุ่นที่เราใช้เมื่อ 10 พ.ย. 2026 ก่อนทำตามให้เปิด [README ล่าสุด](https://github.com/deepseek-ai/deepseek-harness#run-from-source) ด้วย เพราะรุ่น preview อาจเปลี่ยนขั้นตอน

## โมเดลหลักกับผู้ช่วยย่อย ไม่ใช่เรื่องเดียวกัน

จุดที่เราสับสนเองตอนแรก คือ Harness ต่อกับ Claude และ Codex ได้สองแบบ:

- **โมเดลหลัก (model provider):** โมเดลที่เราคุยด้วยในแชตโดยตรง เลือกได้จากเมนูโมเดล เป้าหมายของเราอยู่ตรงนี้ คือใช้บัญชี subscription เป็นโมเดลหลัก
- **ผู้ช่วยย่อย (native subagent):** โมเดลหลักส่งงานหนึ่งชิ้นไปให้ Codex หรือ [Claude Code](/tools/claude-code) ตัวจริงทำ แล้วเอาผลกลับมา DeepSeek มีชุดทางการให้สำหรับ [Codex](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/subagent/subagent-codex/README.md) และ [Claude Code](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/subagent/subagent-claude-code/README.md)

ตอนแรกเราลงชุดผู้ช่วยย่อยก่อน แล้วพบว่ามันไม่ได้ทำให้ Claude ขึ้นมาเป็นโมเดลหลัก จึงต้องติดตั้งปลั๊กอิน subscription แยกอีกตัว ชุดผู้ช่วยย่อยยังติดตั้งอยู่ เราลองเรียก Codex ผ่านชุดนี้แยกต่างหากแล้วตอบกลับได้ แต่ผลนี้เป็นของชุดผู้ช่วยย่อยเท่านั้น ไม่ได้พิสูจน์ว่าปลั๊กอิน subscription ตอบงานได้

## เชื่อม Claude กับ ChatGPT/Codex ด้วยปลั๊กอินชุมชน

ปลั๊กอินที่ใช้คือ [dsh-plugin-subscriptions](https://github.com/V1ki/dsh-plugin-subscriptions) ของ V1ki ซึ่ง**เป็นปลั๊กอินจากชุมชน ไม่ใช่ของ DeepSeek** เราติดตั้งรุ่น 0.9.12 แบบระบุรุ่นแน่นอน และตรวจแล้วว่าไฟล์ที่ได้ตรงกับค่า SHA-512 ที่ npm ประกาศ

```bash title="add-subscriptions.sh"
# Same as Plugins → Add plugin in the web UI. Pin the version you checked.
corepack pnpm dsh plugin --profile web add dsh-plugin-subscriptions@0.9.12
```

หลังติดตั้ง ไม่ต้อง restart เพราะหน้าเว็บโหลดปลั๊กอินใหม่ให้เอง จากนั้น:

1. เปิด **Settings → Subscriptions** แล้วกดเชื่อมบัญชีของแต่ละเจ้า
2. ยืนยันสิทธิ์ในเบราว์เซอร์ ไม่ต้องใส่ API key ของ Anthropic หรือ OpenAI
3. เปิด **New session** เลือก workspace แล้วเลือกโมเดลจากเจ้าที่เชื่อมแล้วในเมนูโมเดล

ผลล่าสุดในเครื่องเรา: ChatGPT/Codex เชื่อม 1 บัญชี Claude เชื่อม 1 บัญชี ทั้งสองอ่านโควตาได้ และแชตใหม่เลือก Claude Opus 5.5 เป็นโมเดลหลักได้

การใช้ subscription ไม่ได้แปลว่าใช้ได้ไม่จำกัด ทุกคำขอยังกินโควตาและอยู่ใต้ข้อกำหนดของแต่ละบัญชีเหมือนเดิม

## ปัญหาที่เจอระหว่างทาง

- **ปุ่ม Log in ของ Claude กดแล้วเหมือนไม่มีอะไรเกิดขึ้น** ปลั๊กอินพยายามนำเข้าข้อมูลล็อกอินจาก Claude Code ที่มีในเครื่องก่อน มันรายงานว่านำเข้าสำเร็จ แต่บัญชีหายไป เราตรวจแล้วพบว่ามันไปหยิบข้อมูลชุดเก่าที่หมดอายุแล้วใน Keychain เราแก้โดยเลือก**ยืนยันสิทธิ์ผ่านเบราว์เซอร์**แทน หลังจากนั้นบัญชีขึ้นปกติพร้อมโควตา เราไม่ได้แก้โค้ดของ Harness หรือของปลั๊กอิน
- **โควตาบัญชี DeepSeek หมดก่อนลองส่งงาน** ตอนให้ DeepSeek เป็นตัวประสานงานแล้วส่งงานต่อให้ Codex ระบบตอบ `ACCOUNT_QUOTA` ก่อน เลยยังทดสอบเส้นทางนี้ไม่สำเร็จ
- **รุ่นโมเดลของ Codex ไม่ตรงกับบัญชี** รุ่นที่ตั้งไว้เป็นค่าเริ่มต้นใช้กับบัญชี ChatGPT นี้ไม่ได้ เราจึงดูรายการโมเดลที่บัญชีใช้ได้จริง แล้วตั้งรุ่นที่ใช้ได้ให้ Harness อย่างเดียว ไม่ได้แก้ค่าตั้งของ Codex ที่ใช้นอก Harness

## สิ่งที่เราชอบ

- **บัญชีหลายเจ้าในหน้าเดียว** จัดการบัญชีและเลือกโมเดลจากที่เดียว ไม่ต้องสลับแอป
- **เห็นโควตาก่อนเริ่มงาน** Claude แสดงทั้งรอบ 5 ชั่วโมงและรายสัปดาห์ Codex แสดงช่วงโควตาของบัญชี ช่วยตัดสินใจว่างานนี้ควรใช้บัญชีไหน แต่ละแผนอาจแสดงไม่เหมือนกัน
- **หน้าเว็บ แต่ทำงานกับไฟล์ในเครื่อง** ใช้เป็นโต๊ะทำงานกับโฟลเดอร์โปรเจกต์ได้จริง โดยให้ agent ทำงานตามสิทธิ์ที่เราตั้ง

## ฟีเจอร์ที่เอกสารบอก แต่เรายังไม่ได้ลอง

ส่วนนี้เราเขียนตามเอกสารต้นทาง ยังไม่ได้ลองเอง:

- **Everything is a plugin และ Creator mode** เว็บทางการสาธิตให้ agent สร้างปลั๊กอินใหม่จากคำขอในแชต
- **ตั้งรายการโมเดลและระดับการคิด** README ของปลั๊กอินบอกว่าเลือกโมเดลที่จะแสดง เปลี่ยนชื่อ และตั้ง Effort หรือ Fast ได้ แต่ใช้ได้เฉพาะโมเดลและบัญชีที่รองรับ
- **ตั้งงานตามเวลาและงานนอกโค้ด** เช่น สรุปรายงานประจำสัปดาห์ หรือทำเอกสารและสไลด์ งานตามเวลาที่รันในเครื่องต้องเปิดเครื่องและเปิดโปรแกรมไว้
- **เครื่องมือสร้างภาพ วิดีโอ และค้นหา** ปลั๊กอินมีให้สำหรับบางเจ้า (เช่น ChatGPT และ Grok) ไม่ได้แปลว่า Claude subscription ทำได้ด้วย

## ความเสี่ยงที่ต้องรู้ก่อนลอง

- ปลั๊กอินนี้ทำโดยชุมชน การที่ล็อกอินได้ไม่ได้แปลว่า Anthropic หรือ OpenAI อนุมัติวิธีล็อกอินทุกแบบที่มันใช้
- **Claude ต้องระวังเป็นพิเศษ** [เอกสารของ Anthropic](https://code.claude.com/docs/en/legal-and-compliance#authentication-and-credential-use) แยกกรณีที่ใช้ Claude Code ตัวจริงโดยไม่ดัดแปลง ออกจากกรณีที่นำข้อมูลล็อกอินของ Claude.ai ไปใช้หรือส่งคำขอผ่านแอปอื่น อ่านข้อกำหนดล่าสุดเองก่อนตัดสินใจ
- มีผู้ใช้[รายงานว่าบัญชี Claude ถูกแบน](https://github.com/anomalyco/opencode/issues/6930)หลังใช้ subscription กับเครื่องมืออื่นเมื่อ ม.ค. 2026 และภายหลังผู้รายงานบอกว่าได้รับการปลดแบน ข้อมูลนี้ไม่พอจะบอกว่าโอกาสโดนแบนมากแค่ไหน หรือสาเหตุคืออะไร
- เราไม่พบหลักฐานว่าปลั๊กอินตัวนี้ทำให้บัญชีใดถูกแบน แต่การไม่พบหลักฐานไม่ได้แปลว่าไม่มีความเสี่ยง
- เรายังไม่ได้วัดความเร็ว คุณภาพคำตอบ หรือค่าใช้จ่าย และยังไม่ได้ใช้ทำโปรเจกต์จริงตั้งแต่ต้นจนจบ

## สรุป

> ถ้าอยากรวมบัญชี Claude กับ ChatGPT/Codex ไว้ในหน้าจอเดียว DeepSeek Harness กับปลั๊กอิน subscription ทำได้ตั้งแต่ติดตั้งจนเลือกโมเดลได้ แต่ก่อนใช้กับบัญชีหลัก ให้อ่านข้อกำหนดของแต่ละเจ้าเอง และลองกับงานเล็ก ๆ ก่อน

ก่อนติดตั้งปลั๊กอินหรือ skill ตัวไหนก็ตาม อ่านเพิ่มได้ที่[ก่อนติดตั้ง skill: ตรวจเครื่องมือและสิทธิ์ให้ครบ](/articles/install-with-permissions)
