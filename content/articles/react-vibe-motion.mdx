## สรุปสั้น ๆ

[React Vibe](https://reactvibe.com/) คือคลังคอมโพเนนต์ React ที่เน้น**แอนิเมชันเป็นหลัก** ไม่ต้องติดตั้ง React Vibe เอง ใช้วิธีเปิดหน้าเอกสาร ก๊อปโค้ดไปวางในโปรเจกต์ แล้วแก้ต่อได้ตามใจ เพราะโค้ดเป็นของเราทั้งหมด

คนที่คอมเมนต์ **motion** ใต้คลิปเราแล้วได้ลิงก์นี้ไป: หมวดที่โชว์ในคลิปคือ [Motion](https://reactvibe.com/docs/motion/overview) เริ่มจากตรงนั้นได้เลย

## มีอะไรให้ใช้บ้าง

หน้าเอกสารบอกว่ามีคอมโพเนนต์ 74 ชิ้นใน 7 หมวด ณ วันที่เราดู (17 พ.ย. 2026):

- **Motion** แผนภาพที่มีจุดแสงวิ่งตามเส้น เช่น Branch Flow, Hub Flow, Converge, Network Pulse, Pipeline เหมาะกับหน้า Hero ของ SaaS ที่อยากโชว์ว่าระบบต่อกับอะไรได้บ้าง หรือข้อมูลไหลผ่านอะไร
- **Backgrounds** พื้นหลังเคลื่อนไหว เช่น Rising Lines, Spotlight Grid
- **Blocks** ส่วนหน้าเว็บสำเร็จรูป เช่น Hero, Pricing, FAQ, Footer
- **Components** ชิ้นเล็ก เช่น ปุ่ม สวิตช์ dropdown badge ที่มีแอนิเมชันในตัว
- **Text** ตัวหนังสือที่ค่อย ๆ โผล่ (Linear Reveal)
- **Dashboard** ชิ้นส่วนหน้าแดชบอร์ด ตาราง กราฟ
- **Templates** เทมเพลตทั้งเว็บ

ข้อควรรู้: หน้า Dashboard Systems บางหน้ามีป้าย **PRO** และหมวด Templates อยู่ใต้หัวข้อ Store แปลว่า**ไม่ใช่ทุกอย่างฟรี** ส่วนที่เราพูดถึงในคลิป (Motion) เปิดดูโค้ดได้ทั้งหมด

## ใช้ยังไง

ทุกหน้าคอมโพเนนต์มีแท็บ **Showcase** (ดูตัวอย่าง) กับ **Source** (ดูโค้ด) ขั้นตอนคือ

1. เลือกคอมโพเนนต์ เปิดแท็บ Source
2. ก๊อปไฟล์ทั้งหมดที่หน้านั้นแสดง ไปวางในโปรเจกต์ของเรา
3. ถ้าหน้านั้นบอกให้ลง `framer-motion` ก็ลงครั้งเดียว (`npm i framer-motion`)
4. ปรับ prop สี ความเร็ว ระยะ ตามที่ตารางในหน้าเอกสารบอก

ทุกชิ้นเขียนด้วย **Tailwind CSS** ถ้าโปรเจกต์ไม่ได้ใช้ Tailwind ต้องแปลง class เอง ซึ่งเสียเวลาพอสมควร และรองรับโหมดมืดผ่าน class `dark` ที่ `<html>` หรือ `<body>`

### ตัวอย่าง Branch Flow

Branch Flow คือกล่องด้านบนหนึ่งกล่อง แตกเส้นโค้งลงไปหาไอคอนหลายตัวด้านล่าง มีจุดแสงวิ่งไปตามเส้น เราเปิดซอร์สดูแล้วพบว่า**ตัวนี้ใช้ SVG `<animateMotion>` ของเบราว์เซอร์ ไม่ได้ import framer-motion** (หน้าเอกสารยังบอกให้ลง framer-motion เพราะเป็นขั้นตอนรวมของทั้งหมวด)

เราลองจริงบน Mac เมื่อ 17 พ.ย. 2026: ก๊อป `BranchFlow.tsx` ไปใส่โปรเจกต์ Vite ใหม่ที่มีแค่ React 19.2 กับ Tailwind 4.3 ไม่ได้ลง framer-motion สั่ง `vite build` ผ่านใน 323ms และเปิดในเบราว์เซอร์แล้วจุดแสงวิ่งตามเส้นครบทุกเส้น ภาพปกบทความนี้คือหน้าจอจริงจากการลองครั้งนั้น

prop ที่ปรับได้ เช่น

| prop | ค่าเริ่มต้น | ใช้ทำอะไร |
|---|---|---|
| `curve` | 120 | ความโค้งของเส้น |
| `particleSpeed` | 2.5 | วินาทีที่จุดแสงวิ่งจนสุดเส้น |
| `particleColor` | `#f97316` | สีจุดแสง |
| `curveColor` | ว่าง | สีเส้น (ว่าง = ปรับตามโหมดสว่าง/มืดเอง) |

ไอคอนด้านล่างเป็น SVG ตัวอย่างที่ฝังมาในไฟล์ ก่อนขึ้นเว็บจริง**ควรเปลี่ยนเป็นโลโก้หรือไอคอนของเราเอง** อย่างน้อยหนึ่งตัวเป็นโลโก้ของบริษัทอื่น (ในภาพปกเราเปลี่ยนเป็นจุดสีธรรมดา) ซึ่งเราไม่มีสิทธิ์ใช้
