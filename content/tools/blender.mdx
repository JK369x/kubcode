## คืออะไร

Blender เป็นโปรแกรมสร้างงาน 3D ครบวงจร ทั้งโมเดล แสง กล้อง แอนิเมชัน และเรนเดอร์ ใช้ฟรีทุกงานรวมงานเชิงพาณิชย์ และรันแบบไม่มีหน้าจอ (`blender -b -P script.py`) ได้ ทุกอย่างในฉากสั่งผ่าน Python ได้ AI agent จึงเขียนสคริปต์สร้างฉากและสั่งเรนเดอร์ให้เราได้โดยที่เราไม่ต้องรู้วิธีใช้ Blender

## ใช้ทำอะไรในงานของเรา

เป็นตัวเรนเดอร์ของ [make-short](/tools/make-short) ซึ่ง Claude Code เขียนสคริปต์ Python สร้างค่ายทหาร ตัวละคร และกล้องทีละช็อต แล้วสั่ง Blender เรนเดอร์ภาพแนวตั้ง 1080×1920 ด้วย EEVEE ตอนเราลองบน Mac (Apple M5, Blender 5.3) ภาพ 15 วินาที 450 เฟรมใช้เวลาเรนเดอร์ราว 7.3 นาที

## สิทธิ์

- ตัวโปรแกรมเป็น GPL ภาพและวิดีโอที่เราเรนเดอร์ออกมาเป็นของเรา ไม่ติดเงื่อนไข GPL
- ชื่อ "Blender" และโลโก้ไม่ได้อยู่ใน GPL ใช้ได้เพื่อบอกว่าใช้ Blender หรือให้เครดิต และห้ามทำให้ดูเหมือนเป็นงานทางการของ Blender Foundation

## ก่อนเริ่ม

- ดาวน์โหลดจาก blender.org หรือบน Mac ใช้ `brew install --cask blender`
- เครื่องควรมีการ์ดจอที่ Blender ใช้ได้ ถ้าใช้แค่ CPU จะเรนเดอร์ช้ามาก
