## คืออะไร

skill ที่ FreshStack เผยแพร่ให้ใช้กับ Claude Code และ [OpenCode](/tools/opencode) รับคำถามแนว "ถ้าเกิดว่า…" หนึ่งบรรทัด แล้วพา agent ผลิตคลิปแอนิเมชันตัวละครเส้นยาว 15–25 วินาทีจนจบ ไม่ใช้โมเดลสร้างภาพหรือวิดีโอเลย ทุกฉากเป็นโค้ด SVG จึงคุมหน้าตาตัวละครให้เหมือนเดิมได้ทุกตอน

## ขั้นตอนที่ skill พาทำ

บท → เสียงบรรยาย → ลำดับช็อต → สตอรีบอร์ดภาพนิ่ง → ตรวจตัวเอง → แอนิเมชัน → เสียงประกอบ → ปรับความดังรวมด้วย [FFmpeg](/tools/ffmpeg) ฉากทั้งหมดเรนเดอร์ด้วย [Remotion](/tools/remotion) และใช้ [ElevenLabs](/tools/elevenlabs) ทำเสียง

## ต้องมีอะไร

- Node 18 ขึ้นไป, Python 3.9 ขึ้นไป (numpy, Pillow), FFmpeg พร้อม ffprobe
- ElevenLabs API key (ต้นทางระบุว่าใช้ราว 150–240 เครดิตต่อตอน)
- คำสั่ง `/what-if` สำหรับ OpenCode อยู่ใน repo แล้ว

## สิทธิ์และข้อควรระวัง

- โค้ดของ skill ใช้ MIT แต่เงื่อนไขของ Remotion และ ElevenLabs ยังมีผลแยกกัน
- ตัวอย่างเสียงใน repo สร้างด้วยแผนเสียเงินของผู้เขียน ไม่ใช่สิทธิ์ใช้เสียงนั้นเชิงพาณิชย์ของเรา
- กติกาของ skill: ใช้ตัวละครและเรื่องที่คิดเอง ไม่เลียนแบบตัวละครดัง และทุกข้อเท็จจริงต้องมีแหล่งอ้างอิง
