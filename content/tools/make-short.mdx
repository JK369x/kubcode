## คืออะไร

skill สำหรับ [Claude Code](/tools/claude-code) ที่เปลี่ยนไอเดียหนึ่งบรรทัดเป็นคลิปสั้นแนวตั้ง ตัวละครทรงเมล็ดถั่วในโลก 3D ที่ดูเหมือนภาพวาด ทุกฉากเขียนเป็นสคริปต์ Python แล้วเรนเดอร์ด้วย [Blender](/tools/blender) ไม่ใช้โมเดลสร้างภาพหรือวิดีโอ

## จุดเด่น

- **critic แยกตัว:** หลังเรนเดอร์ จะเปิด agent ใหม่ที่ไม่ได้สร้างคลิปมาให้คะแนนตาม rubric และบอกวินาทีของทุกจุดที่หักคะแนน ผู้เขียนพบว่า Claude ให้คะแนนงานตัวเอง 6.5 แต่ critic ให้ 4.2
- **ด่านตรวจ:** คุณอนุมัติเรื่อง แผนช็อต และภาพนิ่งก่อน render ทุกครั้ง และไม่มีการโพสต์จนกว่าจะพิมพ์ `go`
- **บันทึกบทเรียน:** ทุกข้อผิดพลาดถูกเขียนเป็นกฎใน `references/lessons.md` ให้รอบต่อไปอ่านก่อน

## ต้องมีอะไร

Claude Code, Blender 5.x, Node 22+, Python 3.10+ (pillow, numpy), FFmpeg และการ์ดจอ ต้นทางสร้างและทดสอบบน Windows กับ Git Bash ส่วนบน Mac เราทำสคริปต์แก้ให้ อ่านใน[บทความ](/articles/make-short-blender)
