## คืออะไร

ปลั๊กอินที่แบ่งงานออกแบบซอฟต์แวร์เป็นสองบทบาท **ช้าง** คือ agent ที่จำทุกอย่างในโปรเจกต์และคุยกับคุณจนได้สเปก **ปลาทอง** คือ agent ใหม่ที่ไม่เห็นบทสนทนาก่อนหน้า อ่านแค่เอกสารกับโค้ดที่อ้างถึง จึงเห็นสิ่งที่ช้างคิดว่า "รู้กันอยู่แล้ว" แต่ไม่ได้เขียนไว้ ส่วน **คุณ** เป็นคนตัดสินใจและอนุมัติสเปกก่อนสร้าง

แนวคิดมาจากบทความของ Dave Rensin เรื่อง Elephants, Goldfish, and the New Golden Age of Software Engineering

## skill ที่มี

- `egm-brainstorm`: คุยไอเดีย แล้วปลาทองหลายตัวช่วยกันท้าทาย ได้ `concepts_brief.md`
- `egm-draft`: เขียนเอกสารออกแบบทีละหัวข้อ หยุดถามคุณทุกหัวข้อ
- `egm-review`: ปลาทองรีวิวเอกสารออกแบบ 5 ขั้น
- `egm-resolve`: ไล่แก้ตามผลรีวิวทีละข้อ
- `egm-bootstrap`: เขียนเอกสารให้โค้ดที่มีอยู่แล้ว
- `egm-review-loop`: เลือกชุดผู้รีวิวเองสำหรับเอกสารแบบอื่น
- `egm-drift-report`: เทียบเอกสารกับโค้ดปัจจุบันว่ายังตรงกันไหม

## ติดตั้ง (Claude Code)

```bash
claude plugin marketplace add google/elephant-goldfish-model
claude plugin install egm@egm
```

ใน Claude Code เรียกด้วย prefix เช่น `/egm:egm-brainstorm` ต้องติดตั้งทั้งปลั๊กอิน เพราะ skill อ่านไฟล์ใน `agents/` กับ `resources/` ตอนรัน และ agent ต้องเปิด subagent ใหม่ได้ ถ้าเปิดไม่ได้ EGM จะหยุดรีวิว
