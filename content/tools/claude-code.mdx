## คืออะไร

Claude Code เป็น AI agent สำหรับงานโค้ดจาก Anthropic ทำงานได้ทั้งใน terminal, IDE, แอปเดสก์ท็อป และเบราว์เซอร์ มันอ่านไฟล์ในโปรเจกต์ แก้โค้ด และรันคำสั่งตามที่เราสั่ง ตัวโปรแกรมไม่ใช่โอเพนซอร์ส ไฟล์ไลเซนส์ใน repo ระบุว่าใช้ตาม Commercial Terms ของ Anthropic

## ใช้ทำอะไรในงานคลิปของเรา

เราใช้ Claude Code เป็น "ผู้เขียน" อีกตัวหนึ่ง มันเปิด skill ของเรา เขียนโค้ดฉาก แล้วสั่งเรนเดอร์ ตัวอย่างใน [growkaz stickman](/skills/growkaz-stickman) และ [thai survival](/skills/thai-survival) มีทั้งชุดที่ Claude Code เขียนและชุดที่ [Codex CLI](/tools/codex-cli) เขียน เทียบกันได้ เพราะผู้เขียนเป็นคนละชั้นกับสไตล์ภาพและตัวเรนเดอร์

## ติดตั้งและเริ่มใช้

- วิธีที่เอกสารแนะนำบน macOS, Linux และ WSL คือ `curl -fsSL https://claude.ai/install.sh | bash` ส่วนบน Windows ใช้ PowerShell `irm https://claude.ai/install.ps1 | iex`
- ติดตั้งผ่าน Homebrew (`brew install --cask claude-code`) หรือ npm (`npm install -g @anthropic-ai/claude-code`, ต้องใช้ Node.js 22 ขึ้นไป) ก็ได้
- เปิดจากในโฟลเดอร์งานด้วยคำสั่ง `claude` แล้วลงชื่อเข้าใช้

## ค่าใช้จ่าย

แผนฟรีของ claude.ai ใช้ Claude Code ไม่ได้ ต้องมีแผน Pro, Max, Ultra, Team หรือ Enterprise หรือบัญชี Console ที่จ่ายตามการใช้ API องค์กรเรียกผ่าน Amazon Bedrock, Google Cloud หรือ Microsoft Foundry ได้ด้วย ราคาเปลี่ยนได้ ดูหน้าราคาของ Claude ก่อนสมัคร

## skill

Claude Code อ่าน skill จากโฟลเดอร์ที่มีไฟล์ `SKILL.md` ไว้ที่ `.claude/skills/<ชื่อ>/` ในโปรเจกต์ หรือ `~/.claude/skills/<ชื่อ>/` สำหรับทุกโปรเจกต์ รูปแบบนี้ตามมาตรฐาน Agent Skills แบบเปิด skill ชุดเดียวกันจึงย้ายไปใช้กับ agent อื่นที่รองรับได้ ดู [ก่อนติดตั้ง skill](/articles/install-with-permissions) ว่าต้องตรวจอะไรก่อนเปิดให้ agent ใช้
