## คืออะไร

ชุด agent skill จากผู้เขียนคนเดียวกับ [What If animation](/tools/what-if-animation) สำหรับทำคลิปสั้นแนะนำเครื่องมือ AI แบบมีคนพูดหน้ากล้อง ประกอบด้วย skill หนึ่งตัวสำหรับเขียนบท และอีกตัวสำหรับตัดต่อใน [Remotion](/tools/remotion) ใส่ซับ ภาพประกอบ และตัวเลขดาวของ GitHub แบบสด โครงของคลิปมาจากการแกะคลิปรีวิวเครื่องมือ 16 คลิป

## สิ่งที่ต้องมีตาม repo

- Node 18 ขึ้นไป, FFmpeg และ Python 3.10 ขึ้นไป (numpy, faster-whisper, Pillow)
- ฟุตเทจของคุณเอง เทมเพลตจะเรนเดอร์ไม่ได้จนกว่าจะใส่ไฟล์ของตัวเอง

## ทำไมเราลิงก์อย่างเดียว

repo นี้ไม่มีไฟล์ไลเซนส์ แม้ README จะบอกว่าแจกให้ใช้ แต่ในทางกฎหมาย งานที่ไม่มีไลเซนส์ยังสงวนสิทธิ์ทุกอย่างไว้กับเจ้าของ เราจึง:

- ไม่คัดลอก ไม่แจก และไม่รวมไฟล์จาก repo นี้ไว้ในเว็บหรือชุดเครื่องมือของเรา
- อธิบายด้วยคำของเราเองและลิงก์ไปต้นทาง
- แนะนำให้ถามเจ้าของ repo โดยตรงก่อนนำไปใช้ในงานเชิงพาณิชย์ หรือรอจนมีไลเซนส์ที่ชัดเจน
